# 🛡️ Antivirus DB - Master Security Suite (V3)

Welcome to **Antivirus DB**, a comprehensive, standalone local endpoint security suite built natively in Python. This project combines a modern desktop control dashboard with a live, real-time background file system interceptor.

## ✨ Core Features
* **🚀 Control Center GUI:** A presentation-ready Windows Graphical User Interface featuring real-time scan logs, progress bars, and targeted system directory mapping.
* **🌐 Cloud Synchronization:** The core engine automatically connects over the internet to fetch and compile the absolute latest threat signature updates dynamically on launch.
* **🔒 Safe Isolation Quarantine:** Active threats are safely stripped of execution permissions, renamed, and moved into a central locked folder vault (`C:\Antivirus_Quarantine`).
* **👀 Background Watchman Shield:** A silent real-time directory listener deployed directly to the Windows Startup queue that intercepts high-risk attachments the exact millisecond they land from web browsers or email clients.

---

## 🚀 How to Install and Run

Sharing this toolkit with a friend or deploying it on a second machine requires no technical setup, Python installations, or code tools out of the box. Follow these quick steps:

1. Click on the **`AntivirusDB_Setup_V3.exe`** file listed in the repository menu above.
2. Click the **Download** icon (the downward-pointing arrow) on the right side of the screen to save the master installer installer file.
3. Navigate to your computer's **Downloads** directory and double-click **`AntivirusDB_Setup_V3.exe`** to trigger the blue Windows Setup Wizard.
4. Click through the wizard prompts, make sure the checkbox for **"Create a desktop shortcut"** is ticked, and hit finish!

*Once installed, double-click the new **Antivirus DB Scanner** icon on your Desktop to begin running high-performance drive diagnostics natively.*
